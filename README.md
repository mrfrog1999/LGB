# 建行理财收益监控

监控中国建设银行代销的**建信理财**产品（如「建信宝按日开放式产品」各期次）的**七日年化收益率**，
每天自动抓取并推送到邮箱；网页上输入本金和买入日期后，按每日收益率**滚动复利**估算收益。

## 数据来源

建行官网「理财产品信息披露 → 产品存续期公告」提供公开查询接口，无需登录：

1. **按产品名称检索公告**
   `GET https://ccb.com/tran/WCCMainPlatV5?TXCODE=NLCQ88&Fnd_Nm=<产品名称>&Prim_CL_ID=05&...`
   返回 JSON，含每个期次的产品代码（如第4期 `JXJXBGS2023060204`）。
2. **下载净值公告 PDF**
   `GET ...?TXCODE=NLCQ89&Itt_Fcn_Dsc=<公告编号>`
   一份 PDF 里逐日列出：净值日期 / 份额净值 / 七日年化收益率 / 每万份收益。

因为用的是官方披露的 PDF，稳定、口径准确，也不依赖页面渲染（镜像里不需要浏览器）。
一份公告通常带**最近约 10 天**的逐日明细（更早的用省略号折叠），所以历史数据靠每天抓取逐步积累。

## 快速开始

```bash
cp .env.example .env      # 填 SMTP 账号（QQ 邮箱要填授权码，不是登录密码）
docker compose up -d --build
```

打开 `http://localhost:8080`。

## 网页用法

1. **搜索产品**：点「搜索产品」，输入 `建信宝按日开放式`（或任意系列关键词），
   弹窗会列出该系列**所有期次**（第4、5、6…期），勾选要监控的即可。
2. **设本金与买入日**：每张卡片上填「本金」（即买入金额）和「买入日」，点「保存并重算」。
3. **看收益**：卡片显示最新七日年化、当前本息、累计收益、持有天数、日均收益；
   点「明细」展开本息走势曲线和逐日明细表。
4. **同步**：卡片上的「同步」拉取该产品最新公告；顶部「同步全部」一次同步所有产品。
5. **邮件**：填好 SMTP 后点「发送测试邮件」验证；之后每天 `FETCH_TIME` 自动同步并推送日报。

## 收益计算口径

```
当日收益 = 当日余额 × 七日年化收益率 ÷ 365
次日余额 = 当日余额 + 当日收益      （滚动复利）
```

- 七日年化是过去 7 个自然日收益折算的年化值，这里当作当日年化使用，属于**估算**。
- 未披露的日期（周末、节假日）沿用最近一次披露的收益率，明细表里标 `*`。
- 区间年化 = (期末本息 ÷ 本金)^(365/持有天数) - 1。

## 环境变量

| 变量 | 说明 | 默认 |
|---|---|---|
| `BOOTSTRAP_CODE` / `BOOTSTRAP_NAME` | 首次启动自动订阅的产品 | 建信宝第4期 |
| `SEARCH_KEYWORD` | 搜索框默认关键词 | 建信宝按日开放式 |
| `DEFAULT_PRINCIPAL` | 新增产品预填本金 | 100000 |
| `FETCH_TIME` | 每天抓取并推送的时间 | 09:10 |
| `FETCH_ON_START` | 启动时缺数据是否立即抓 | true |
| `MAIL_ENABLED` / `SMTP_*` / `MAIL_TO` | 邮件配置 | — |
| `DB_PATH` | SQLite 路径 | /data/data.db |

## 目录结构

```
app/
  main.py        FastAPI 路由（网页 + API）
  config.py      环境变量配置
  db.py          SQLite：products / rates / settings / logs
  notice.py      建行公告检索、PDF 下载与解析
  service.py     业务编排：搜索、同步、测算、汇总、邮件
  calc.py        滚动复利计算
  mailer.py      SMTP 发送 + 日报模板
  scheduler.py   APScheduler 每日任务
  static/        网页（index.html / style.css / app.js）
data/            SQLite 数据（挂载出来持久化）
```

## 常见问题

- **搜不到产品**：换更短的关键词（如只填「建信宝」），或确认产品近期有净值公告。
- **只有 10 天数据**：公告 PDF 只列最近约 10 天，程序每天跑会自动累积；也可用「同步」补抓。
- **邮件发不出**：QQ/163 邮箱需要在网页端开启 SMTP 并使用**授权码**；端口 465 用 SSL，587 用 STARTTLS。
- **收益率显示 `--`**：该产品当期在手机上不展示收益率，但净值公告 PDF 里通常有；同步成功后即显示。
